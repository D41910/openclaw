## 2026.10.4


### v2026.10.4

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.10.4).

OpenClaw v2026.10.4 fixes update and recovery problems, including interrupted work after sleep or clock changes and chats stuck after an update, alongside repairs for messaging, model tools and sign-in.

**Release scale:** 44 pull requests, 15 direct commits, and 43 contributors.

#### Web UI

- **Chat refresh after updates.** Chats stuck on “Server updated” can refresh back to the same conversation link. If your tab was open before updating, save unsaved work and reload it once to load this fix. [#168941](https://github.com/openclaw/openclaw/pull/168941), thanks to [@steipete](https://github.com/steipete).

#### Updates and Maintenance

- **Sleep and clock changes.** Fixed unnecessary interruptions after computer sleep or backward clock changes, with clearer [restart guidance](https://docs.openclaw.ai/gateway/restart-recovery) when OpenClaw loses access to its saved state. [#170790](https://github.com/openclaw/openclaw/pull/170790), thanks to [@steipete](https://github.com/steipete), [@jjjhenriksen](https://github.com/jjjhenriksen), [@AnvinaLI](https://github.com/AnvinaLI), [@sgh6688](https://github.com/sgh6688), [@waynegault](https://github.com/waynegault), [@andersgreg](https://github.com/andersgreg) and [@shawnholt](https://github.com/shawnholt).
- **Gateway shutdown.** Stalled conversation indexing gets a five-second grace before cancellation, preserving saved transcripts for [restart recovery](https://docs.openclaw.ai/gateway/restart-recovery). Shutdown also finishes accepted session updates before closing connected clients. [#170493](https://github.com/openclaw/openclaw/pull/170493), [#170555](https://github.com/openclaw/openclaw/pull/170555), thanks to [@steipete](https://github.com/steipete), [@Oldrich333](https://github.com/Oldrich333) and [@O96a](https://github.com/O96a).
- **Old login files.** Unused retired OAuth files no longer block Doctor, updates or Docker startup, and remain preserved. Referenced files still need the documented [2026.9.7 recovery on the original host](https://docs.openclaw.ai/gateway/doctor/config-migrations#retention-policy). [#165420](https://github.com/openclaw/openclaw/pull/165420), thanks to [@obviyus](https://github.com/obviyus).
- **Update snapshots.** An updater containing this fix stops falsely reporting that an unchanged database changed during capture. Later real changes can still prevent [automatic restoration](https://docs.openclaw.ai/install/updating/rollback-and-recovery). [#170351](https://github.com/openclaw/openclaw/pull/170351), thanks to [@DonnieFi](https://github.com/DonnieFi) and [@RomneyDa](https://github.com/RomneyDa).
- **Updates after data migration.** Fixed false verification failures when capturing configuration after data migration. Saved restart warnings also clear when the Gateway reports the target version, though different builds can share that version. See [rollback and recovery](https://docs.openclaw.ai/install/updating/rollback-and-recovery). [#170130](https://github.com/openclaw/openclaw/pull/170130), thanks to [@steipete](https://github.com/steipete) and [@angeliti999](https://github.com/angeliti999).
- **Temporary update files.** Doctor and updates can remove abandoned temporary update directories despite unrelated system processes, including ordinary Linux systemd user sessions. Directories still used by live OpenClaw processes remain protected. [#166335](https://github.com/openclaw/openclaw/pull/166335), [#171488](https://github.com/openclaw/openclaw/pull/171488), thanks to [@vincentkoc](https://github.com/vincentkoc), [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).
- **Temporary disk use.** Update checks reuse eligible prepared database copies instead of duplicating them again, and give clearer retry guidance for space failures. [#167451](https://github.com/openclaw/openclaw/pull/167451), thanks to [@steipete](https://github.com/steipete), [@iFadi](https://github.com/iFadi), [@dankarization](https://github.com/dankarization), [@azuretek](https://github.com/azuretek) and [@davidcittadini](https://github.com/davidcittadini).
- **Update progress.** Temporary congestion while printing progress no longer aborts update inspection, and terminal progress waits through Doctor maintenance before resuming. [#168493](https://github.com/openclaw/openclaw/pull/168493), [#171454](https://github.com/openclaw/openclaw/pull/171454), thanks to [@vincentkoc](https://github.com/vincentkoc), [@creanet-64](https://github.com/creanet-64), [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).
- **Update failure guidance.** Snapshot-preparation failures now point to the snapshot step that failed, instead of runtime verification that never ran. [#171457](https://github.com/openclaw/openclaw/pull/171457), thanks to [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).
- **Maintenance warnings.** Completed plugin upgrades stop leaving stale “unfinished” warnings in [update history](https://docs.openclaw.ai/cli/update/status-and-history). Expected database maintenance also stops producing false checkpoint-failure warnings. [#170413](https://github.com/openclaw/openclaw/pull/170413), [#170783](https://github.com/openclaw/openclaw/pull/170783), thanks to [@RomneyDa](https://github.com/RomneyDa), [@DonnieFi](https://github.com/DonnieFi) and [@steipete](https://github.com/steipete).
- **Scheduled work during updates.** Scheduled jobs and cleanup can save their work while a busy updater waits to record its progress, instead of being blocked by that wait. This applies once the installed updater contains the fix. [#171493](https://github.com/openclaw/openclaw/pull/171493), thanks to [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).
- **Schedule inspection during recovery.** Updates and Doctor can continue when optional memory dreaming schedule checks fail, preserving scheduled jobs. Retry pending dreaming repairs with `openclaw doctor --fix`. Successful job-list reads also survive temporary snapshot cleanup failures. [#170754](https://github.com/openclaw/openclaw/pull/170754), thanks to [@RomneyDa](https://github.com/RomneyDa), [@aniruddhaadak80](https://github.com/aniruddhaadak80) and [@anhnt3](https://github.com/anhnt3).
- **Delegated update repair.** Delegated repair work spends less time rechecking permissions and can reach repair tools before timing out. [#166847](https://github.com/openclaw/openclaw/pull/166847), thanks to [@steipete](https://github.com/steipete).
- **Mac service restart and repair.** Fixed false process-inspection refusals when restarting from an external Mac terminal. Doctor also recognizes when the background service has already loaded during a concurrent start. [#170354](https://github.com/openclaw/openclaw/pull/170354), [#170740](https://github.com/openclaw/openclaw/pull/170740), thanks to [@RomneyDa](https://github.com/RomneyDa).
- **Offline app-owned repair.** Standalone Doctor can repair the same account's configuration and state when an app-owned Gateway is verified offline. [Restart or update through OpenClaw.app](https://docs.openclaw.ai/gateway/doctor/gateway-and-services) afterward. [#170768](https://github.com/openclaw/openclaw/pull/170768), thanks to [@RomneyDa](https://github.com/RomneyDa) and [@shanselman](https://github.com/shanselman).
- **Tailscale diagnosis in Doctor.** Doctor identifies missing Tailscale startup prerequisites and points to the relevant recovery step. [#166947](https://github.com/openclaw/openclaw/pull/166947), thanks to [@RomneyDa](https://github.com/RomneyDa) and [@odrobnik](https://github.com/odrobnik).

#### Messaging

- **Telegram polling.** Fixed a polling-worker startup failure that prevented Telegram messages from arriving in affected installations. [#154286](https://github.com/openclaw/openclaw/pull/154286), thanks to [@xydt-juyaohui](https://github.com/xydt-juyaohui), [@steipete](https://github.com/steipete) and [@markfietje](https://github.com/markfietje).
- **IRC replies.** Long replies containing Chinese, Japanese or Korean text and emoji arrive without losing forwarded chunks. [#159730](https://github.com/openclaw/openclaw/pull/159730), thanks to [@rodricksz4h5](https://github.com/rodricksz4h5) and [@obviyus](https://github.com/obviyus).
- **Replies on macOS.** Fixed a temporary-directory path mismatch that restarted the channel and replayed an incoming message while finishing its reply. [#166462](https://github.com/openclaw/openclaw/pull/166462), thanks to [@ericcaiwx-star](https://github.com/ericcaiwx-star).
- **Feishu settings reload.** Feishu DMs keep receiving replies when a settings reload overlaps a reply already underway, without needing an OpenClaw restart. [#169226](https://github.com/openclaw/openclaw/pull/169226), thanks to [@ruel225](https://github.com/ruel225), [@obviyus](https://github.com/obviyus), [@junniar](https://github.com/junniar) and [@PratikRai0101](https://github.com/PratikRai0101).
- **Discord voice changes.** You can [change voices](https://docs.openclaw.ai/nodes/talk/realtime-sessions#choose-a-talk-voice-from-chat) and continue asking for agent checks in the same call without leaving and rejoining. [#171029](https://github.com/openclaw/openclaw/pull/171029), thanks to [@ericcaiwx-star](https://github.com/ericcaiwx-star), [@steipete](https://github.com/steipete) and [@brainmonger](https://github.com/brainmonger).

#### Memory

- **Manual compaction.** [`/compact`](https://docs.openclaw.ai/concepts/compaction) gives an active answer up to 60 seconds to finish. If it cancels the turn, its status tells you to resend the original request. [#166163](https://github.com/openclaw/openclaw/pull/166163), thanks to [@holny](https://github.com/holny), [@steipete](https://github.com/steipete) and [@alexph-dev](https://github.com/alexph-dev).

#### Native Apps

- **Mac app recovery.** The updated Mac app preserves an already-newer managed Gateway during setup and recovery, and can restore its missing Node background service using that installation. [#170766](https://github.com/openclaw/openclaw/pull/170766), thanks to [@RomneyDa](https://github.com/RomneyDa).

#### Models and Providers

- **OpenAI reasoning with tools.** Eligible reasoning-model tool turns on the [official OpenAI API](https://docs.openclaw.ai/providers/openai/advanced) keep reasoning instead of failing or retrying with reasoning disabled. [#166182](https://github.com/openclaw/openclaw/pull/166182), thanks to [@obviyus](https://github.com/obviyus) and [@AsTutoAI](https://github.com/AsTutoAI).
- **Claude CLI conversation history.** Switching between a messaging channel and web chat keeps the latest history in the same [Claude CLI conversation](https://docs.openclaw.ai/gateway/cli-backends), preventing new branches that miss intervening actions. [#167241](https://github.com/openclaw/openclaw/pull/167241), thanks to [@steipete](https://github.com/steipete) and [@cmatrx0](https://github.com/cmatrx0).

#### Browser and Computer Use

- **Headless browser sign-in.** Headless Chromium dismisses blocking passkey prompts so clicks and keys work and you can choose another login method. [Passkeys still need a headed browser](https://docs.openclaw.ai/tools/browser-login#passkeys-in-headless-browsers), and an already-stuck page needs a reload. [#170857](https://github.com/openclaw/openclaw/pull/170857), thanks to [@trukhinyuri](https://github.com/trukhinyuri) and [@steipete](https://github.com/steipete).

#### Plugins and Integrations

- **Standalone plugin hooks.** Explicitly enabled standalone plugin files register their hooks when OpenClaw starts, so configured [tool policies](https://docs.openclaw.ai/plugins/hooks/tool-policy) and automations take effect. Listing a file in load paths alone does not [enable it](https://docs.openclaw.ai/gateway/config-extensions). [#171330](https://github.com/openclaw/openclaw/pull/171330), thanks to [@holgergruenhagen](https://github.com/holgergruenhagen) and [@obviyus](https://github.com/obviyus).
- **MCP sign-in callbacks.** [MCP sign-in](https://docs.openclaw.ai/cli/mcp/transports) can finish when a provider registered the same local HTTP callback without its dynamic port, addressing the reported Dropbox case. [#170876](https://github.com/openclaw/openclaw/pull/170876), thanks to [@steipete](https://github.com/steipete) and [@9fw2pq8sgb-art](https://github.com/9fw2pq8sgb-art).
- **Interrupted Tailscale startup.** Interrupted starts clean up the Tailscale process OpenClaw started, preventing its leftover route from blocking the next start. Privileged cleanup needs the [documented sudo permission or Tailscale operator setup](https://docs.openclaw.ai/gateway/tailscale); existing processes with uncertain ownership need manual recovery. [#167514](https://github.com/openclaw/openclaw/pull/167514), thanks to [@steipete](https://github.com/steipete) and [@pandysp](https://github.com/pandysp).
- **Local access when Serve is disabled.** A confirmed Tailscale Serve-policy denial still allows authenticated access on the same computer. To regain remote access, [restore the tailnet policy and restart OpenClaw](https://docs.openclaw.ai/gateway/tailscale). [#171509](https://github.com/openclaw/openclaw/pull/171509), thanks to [@RomneyDa](https://github.com/RomneyDa).

#### Security and Privacy

- **Tlon group-DM permissions.** Unverified group-DM author claims no longer gain owner commands, approval/admin actions or elevated tool permissions. A group member can still pose as an allowed sender to chat with the agent, and replies go to the impersonated sender's private conversation. After approving a pending DM saved before updating, [ask the sender to resend it](https://docs.openclaw.ai/channels/tlon). [#165801](https://github.com/openclaw/openclaw/pull/165801), thanks to [@eleqtrizit](https://github.com/eleqtrizit).

#### Quality-of-Life Improvements

- **Agent messages and follow-ups.** Fixed a launch failure that could stop a message to another agent or a subagent follow-up before it produced a reply. [#170077](https://github.com/openclaw/openclaw/pull/170077), thanks to [@steipete](https://github.com/steipete), [@mariorivas1](https://github.com/mariorivas1) and [@ghbalf](https://github.com/ghbalf).

#### Other Bug Fixes

- **Node worker memory limits.** Node workers can honor their configured JavaScript heap limits when OpenClaw starts with a larger heap setting, while the main process keeps its own heap size. [b77060f](https://github.com/openclaw/openclaw/commit/b77060fc6c248f0dd3fed9c7d3903b73117da6d2), thanks to [@xydigitLybnnnn](https://github.com/xydigitLybnnnn).
